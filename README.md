## 贵出来的钱买的是什么：SPT住宅IP、NVMe和5个IPv6

丽萨主机越南节点用的是越南西贡邮电（SPT，Saigon Post and Telecommunications）的宽带IP段，属于越南本土运营商的家宽资源，不是数据中心段。Ping0把测试IP识别为住宅/家宽，IPinfo的Company字段显示为ISP类型，历史记录比较干净。

这类IP的价值集中在平台识别环节。TikTok、Shopee这类平台对机房IP段的判定越来越严，住宅段在账号注册和日常运营时的通过率更高，账号被划进本地流量池的概率也更大。数据中心IP便宜，但这一步就容易卡住。

配套的硬件是NVMe固态，全系100到200Mbps带宽，每台额外给5个原生越南IPv6。IPv6数量看起来不起眼，实际做多服务绑定、给不同程序分配独立出口地址时能用上。

公开测评给出的数据（第三方测试，非官方）：测试机为Intel Xeon E5-2686 v4，磁盘I/O约526MB/s，上传约189Mbps、下载约213Mbps，标称100Mbps的套餐跑出这个数字说明带宽没有严重超售。

机房位置在不同来源里有胡志明市和河内两种写法，官方产品页以胡志明市为主。SPT的宽带资源集中在越南南部，胡志明市的说法更可信，下单页会显示具体机房，付款前扫一眼。

## 网络表现：非大陆直连，联通270ms要中转

公开测评的延迟数据：本地Ping平均288ms，全国三网平均184ms，其中电信210ms、联通270ms、移动96ms，港澳台及东南亚节点约40ms，测试期间丢包较少。

移动96ms是这组数据里唯一能算"能用"的数字，联通270ms基本告别直连。去程路由走的是绕行路径，电信经香港、东京、新加坡进越南，或者经洛杉矶进越南，不同测评的描述略有差异，共同结论是都不走大陆直连优化。官方页面也写明是国际线路，建议中转使用，建议开BBR。

这意味着什么：拿它当网页后台、SSH管理、跑自动化脚本，配个中转或者前置代理，体验可以接受；指望它当低延迟远程桌面或者实时直播推流的主线路，270ms的联通延迟会让你难受。做TikTok账号挂机、定时发布、素材上传这类对延迟不敏感的操作，绕路影响不大。
